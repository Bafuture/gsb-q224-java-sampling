## 实现说明

纯 JDK 实现（无第三方运行时依赖），代码位于
`src/main/java/com/example/gsb/sampling/`：

| 类 | 职责 |
|----|------|
| `ReservoirSampler<T>` | 等概率蓄水池抽样（Algorithm R） |
| `WeightedReservoirSampler<T>` | 带权蓄水池抽样（A-Res：key = u^(1/w)） |
| `StratifiedSampler<T, K>` | 分层抽样，每层独立蓄水池，层容量可配置 |
| `SamplingStats` | 统计记录：已处理总量、容量、样本数、选择概率说明 |

### 1. 等概率蓄水池抽样原理（Algorithm R）

流式处理，事先不需要知道总量 N，全程 O(k) 内存：

1. 前 k 条数据直接放入蓄水池；
2. 处理第 i 条数据（i 从 0 开始，i ≥ k）时，在 [0, i] 均匀取随机整数 j，
   若 j < k 则用新数据替换蓄水池第 j 位，否则丢弃。

等概率性（归纳证明）：设前 i+1 条数据中每条留在池中的概率为 k/(i+1)。
处理第 i+1 条时，新数据以 k/(i+2) 入池；池内旧元素存活概率为
`(i+2-k)/(i+2) + k/(i+2)·(k-1)/k = (i+1)/(i+2)`，
故旧元素总入选概率为 `k/(i+1)·(i+1)/(i+2) = k/(i+2)`。
因此任意时刻每条数据入选概率均为 `min(1, k/N)`，与到达顺序无关。

### 2. 带权抽样原理（A-Res）

每条数据计算随机键 `key = u^(1/w)`（u 在 (0,1] 均匀采样，w 为权重），
用最小堆始终保留 key 最大的 k 条。权重越大，键的分布越靠大端。
k=1 时元素 i 的入选概率恰为 `w_i / Σw`；k>1 时等价于不放回地按权重比例
逐次抽取。

### 3. 分层抽样

按分类函数（如 `User::tier`）把数据归入互斥的层，每层持有独立的
`ReservoirSampler`，层容量通过 `Function<K, Integer>` 逐层配置。
层间数据流完全隔离；每层随机种子由 `主种子 XOR (hashCode(层键)·常数)`
确定性派生，因此结果与层的到达顺序无关，且整体可用一个种子复现。

### 4. 可复现 / 快照 / 统计

- 随机源全部来自构造参数 `long seed`（`java.util.Random`，算法跨 JDK 版本确定），
  同种子 + 同输入序列结果完全一致；
- `snapshot()` 返回防御性拷贝，外部修改与继续投喂都不影响已取快照和后续抽样；
- `stats()` 返回已处理量、容量、当前样本数及选择概率说明，
  分层抽样按层给出统计。

### 用法示例

```java
// 等概率：固定 100 条样本
var reservoir = new ReservoirSampler<Log>(100, 42L);
stream.forEach(reservoir::offer);
List<Log> sample = reservoir.snapshot();

// 带权：错误日志权重更高
var weighted = new WeightedReservoirSampler<Log>(100, 42L);
weighted.offer(log, log.level().equals("ERROR") ? 5.0 : 1.0);

// 分层：vip 20 条、normal 50 条
var stratified = new StratifiedSampler<User, String>(
        User::tier, tier -> tier.equals("vip") ? 20 : 50, 42L);
users.forEach(stratified::offer);
Map<String, List<User>> all = stratified.snapshot();
Map<String, SamplingStats> stats = stratified.stats();
```
