## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

我们要从不断到达的数据流里抽取样本做分析，事先不知道总量，还希望不同层级的样本比例可控。请从零实现一个抽样组件。仓库目前只有一个空的 Maven 工程（pom.xml 只声明 JUnit 5 与 AssertJ）。要求：1) 实现蓄水池抽样：流式处理 N 条数据并保持固定大小样本，每条数据被选中的概率相同，需说明算法原理；2) 支持带权抽样：权重不同的元素被选中概率按权重比例变化；3) 支持分层抽样：按指定维度分层，各层独立维护样本，层内样本量可配置；4) 抽样结果可复现：给定随机种子后多次运行结果完全一致；5) 支持样本快照：取当前样本不影响后续抽样；6) 支持统计：已处理总量、样本容量、各层样本数与选择概率说明；7) 用小规模全量数据验证抽样均匀性（给出实测分布数据）；8) 测试覆盖等概率、带权比例、分层隔离、种子可复现、快照隔离与均匀性验证；`mvn -q verify` 一条命令跑通。
