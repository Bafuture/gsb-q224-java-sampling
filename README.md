## 实现说明（分支 B）

### 模块结构（`com.example.gsb.sampling`）

| 类 | 职责 |
|----|------|
| `ReservoirSampler<T>` | 等概率蓄水池抽样（Algorithm R） |
| `WeightedReservoirSampler<T>` | 带权蓄水池抽样（A-Res） |
| `StratifiedSampler<T, K>` | 分层抽样：按维度分层，各层独立蓄水池、容量可配，可选层内带权 |
| `Seeds` | SplitMix64 种子混洗，保证“基础种子+序号”式重复试验统计独立 |
| `SamplingDemo` | 可运行演示，打印实测分布数据 |

### 算法原理

- **等概率（Algorithm R, Vitter 1985）**：容量 k 的池子，前 k 条直接入池；第 i 条（i>k）以 k/i 的概率替换池中均匀随机位置。归纳可证：处理完 n 条后，任意一条已到达数据留在池中的概率恰为 k/n，与到达顺序无关，空间 O(k)、单条 O(1)，无需预知总量。
- **带权（A-Res, Efraimidis & Spirakis 2005）**：每条数据计算键 key = u^(1/w)（u~Uniform(0,1)），用最小堆保留 key 最大的 k 条。P(key≤x)=x^w，权重越大 key 越接近 1，入选概率随权重单调上升；k=1 时 P(i)=w_i/Σw 精确成立，k>1 时近似与权重成正比（等价于按权重不放回抽样）。
- **分层**：每条数据经分类函数归入某层，层首次出现时惰性创建独立蓄水池（等权或带权），层间互不影响；各层种子由主种子经 SplitMix64 派生，给定种子多次运行结果完全一致。
- **可复现性**：所有采样器使用显式播种的 `java.util.Random`，并对种子做确定性混洗——相同种子结果逐位一致，相邻种子（重复试验常用）统计独立。
- **快照**：`snapshot()`/`snapshotAll()` 返回不可变独立副本，继续抽样不影响已取快照。
- **统计**：`processedCount()`、`capacity()`、`stats()` 提供已处理总量、容量、各层样本数与选择概率说明（等权为 min(1,k/n)，带权为 ∝w_i 的说明）。

### 实测分布数据（`mvn -q verify` 时由测试打印）

等概率均匀性（n=10，k=3，60,000 次完整抽样，理论命中率 30%）：

```
item 0: 29.877%   item 1: 30.082%   item 2: 30.338%   item 3: 29.892%   item 4: 29.832%
item 5: 30.162%   item 6: 29.913%   item 7: 29.905%   item 8: 29.832%   item 9: 30.168%
chi2 = 5.515（df=9，α=0.001 临界值 27.877，远小于临界值 → 均匀）
```

带权比例（权重 1:3，k=1，60,000 次，理论 25%:75%）：实测 24.887% : 75.113%。

分层带权（层 A 内权重 1:4，k=1，20,000 次，理论 80%）：实测 80.040%。

### 测试覆盖（19 个用例，4 个测试类）

- `ReservoirSamplerTest`：容量约束、等概率、快照隔离、种子可复现、非法参数
- `WeightedReservoirSamplerTest`：权重比例 1:3、k=2 权重单调性、非法权重、可复现、快照隔离
- `StratifiedSamplerTest`：分层隔离、层容量配置、统计字段、可复现、快照隔离、层内带权比例
- `UniformityTest`：小规模全量数据均匀性（卡方检验 + 偏差上限，打印实测分布）
